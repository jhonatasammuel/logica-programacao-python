# 🍱 Sistema de Vendas de Marmitas (Interface de Checkout)

Este script simula o atendimento de uma loja de marmitas, focando na experiência do usuário e na validação rigorosa de dados de entrada.

### ⚙️ Funcionalidades e Regras de Negócio:
- **Menu Interativo**: Exibição de opções de sabores (Bife Acebolado e Filé de Frango) e tamanhos (P/M/G).
- **Validação de Dados**: Sistema de segurança que impede entradas inválidas de sabor ou tamanho, solicitando a correção imediata ao usuário.
- **Acumulador de Pedidos**: Permite que o cliente realize múltiplas compras em uma única sessão, somando os valores automaticamente.
- **Controle de Fluxo**: Uso estratégico de `while`, `break` e `continue` para uma navegação fluida.

### 🧠 Conceitos Técnicos Aplicados:
- **Estruturas de Repetição**: Loop infinito controlado para manter a aplicação ativa.
- **Condicionais Aninhadas**: Lógica complexa para cruzamento de preços entre sabores e tamanhos.
- **Tratamento de Erros**: Feedback em tempo real para o usuário em caso de inputs incorretos.
- **Boas Práticas**: Código 100% comentado seguindo padrões de legibilidade.
