# 🛒 App de Vendas com Cálculo de Juros

Este script foi desenvolvido como parte dos estudos de lógica de programação em Python. O objetivo foi criar um sistema que calcula o valor de parcelas e o total com juros de acordo com a escolha do cliente.

### ⚙️ Funcionalidades:

- Interface de boas-vindas personalizada.
- Entrada de dados para valor do pedido e número de parcelas.
- Cálculo dinâmico de juros baseado em faixas de parcelamento.
- Exibição clara do valor unitário da parcela e do montante total.

### 🧠 Conceitos Aplicados:

- Estruturas condicionais (`if`, `elif`, `else`).
- Manipulação de tipos de dados (Float e Int).
- Lógica matemática para sistemas financeiros.
- Documentação de código através de comentários.
