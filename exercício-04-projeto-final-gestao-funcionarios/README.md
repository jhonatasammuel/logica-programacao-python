# 👥 Sistema de Gerenciamento de Funcionários (CRUD)

Este é o projeto mais complexo da trilha de lógica de programação, consistindo em um software completo de gestão de RH. O sistema permite o ciclo de vida completo de um registro: cadastro, consulta filtrada e remoção.

### ⚙️ Funcionalidades Principais:
- **Gestão de Identidade**: Uso de `id_global` para garantir que cada funcionário tenha um registro único.
- **Consultas Multi-Filtro**: Interface de busca que permite localizar colaboradores por ID, por Setor ou listar o quadro completo.
- **Persistência em Memória**: Uso de uma estrutura de **Lista de Dicionários** para armazenamento e manipulação ágil de dados.
- **Módulo de Remoção**: Funcionalidade de exclusão de registros com validação de existência de ID.

### 🧠 Domínio Técnico Demonstrado:
- **Dicionários e Listas**: Manipulação profunda de estruturas de dados compostas.
- **Modularização**: Código totalmente organizado em funções com passagem de parâmetros e retornos.
- **Menu de Navegação Complexo**: Sistema de menus aninhados com validação de opções e loops de repetição `while`.
- **Boas Práticas de Código**: Documentação técnica através de comentários para facilitar a manutenção do software.
