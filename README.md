# 🐍 Lógica de Programação e Algoritmos com Python

Este repositório contém uma trilha de projetos práticos desenvolvidos durante meus estudos de tecnologia. Os exercícios simulam cenários reais de mercado, focando em estruturação de dados, automação de processos e experiência do usuário (UX).

## 🚀 Projetos no Repositório

### 1. 🛒 [Sistema de Vendas e Parcelamento](./exercicio-01-vendas)
- **Foco**: Estruturas condicionais e lógica financeira.
- **Resumo**: Aplicativo que calcula juros progressivos baseados na quantidade de parcelas de uma compra.

### 2. 🍱 [Checkout de Vendas (Marmitaria)](./exercicio-02-marmitas)
- **Foco**: Validação de dados e loops de repetição.
- **Resumo**: Simulador de PDV com tratamento de erros de input e acumulador de valores para múltiplos pedidos.

### 3. 👕 [Gestão de Cobrança e Logística](./exercicio-03-atacado)
- **Foco**: Programação Modular (Funções) e Try/Except.
- **Resumo**: Sistema para fábrica de camisetas com cálculo de descontos por volume e integração de taxas de frete.

### 👥 4. [Gerenciamento de Funcionários (CRUD)](./exercicio-04-rh)
- **Foco**: Engenharia de Software e Estruturas Compostas.
- **Resumo**: O projeto mais robusto da trilha. Um software completo que permite cadastrar, consultar (por ID ou Setor) e remover registros em uma lista de dicionários.

---

## 🛠️ Tecnologias e Conceitos Aplicados
- **Lógica de Decisão**: `if`, `elif`, `else`.
- **Estruturas de Repetição**: `while`, `for`, `break`, `continue`.
- **Coleções de Dados**: Listas e Dicionários (JSON-like structures).
- **Tratamento de Exceções**: Blocos `try/except` para robustez do software.
- **Modularização**: Criação de funções com passagem de parâmetros e retornos.
